# Data and code: popularity and trade of RENISUS medicinal plants on the Brazilian internet

Repository accompanying the manuscript *"Exploring the popularity and trade of medicinal plants on the Brazilian internet"*
(Silva, Brito Junior and Albuquerque), submitted to *Acta Botanica Brasilica*.

The study is an exploratory analysis of the 71 species of the Brazilian national list of medicinal plants of interest to the public
health system (RENISUS, Ministério da Saúde 2009), based on three public sources:

1. **Google Trends** monthly search popularity (Brazil, January 2004 to December 2023), analysed with interrupted time series
   (segmented OLS with Newey-West standard errors) around the publication of RENISUS (February 2009).
2. **Mercado Livre** product listings, collected by web scraping, manually filtered, recategorized and deduplicated.
3. **ANVISA** database of registered medicines (valid vs. non-valid registry per species).

## How to reproduce

Run all scripts from the repository root, in the order below. Scripts 01, 02 and 04a collect data again from the web and are **not
needed** to reproduce the analyses, because the collected data are provided in `data/`.

| Step | Script | Input | Output |
|---|---|---|---|
| 1 | `01_collect_entity_ids_gkgraphR.R` | Google API key | Knowledge Graph IDs (see `renisus_knowledge_graph_ids.csv`) |
| 2 | `02_collect_google_trends.R` | IDs, Google API key | `data/raw/gtrends_monthly_raw.xlsx` |
| 3 | `03_gt_its_ols_newey_west.R` | Google Trends series | `data/processed/its_results_*.csv` |
| 4a | `04a_collect_mercado_livre_colab.py` | Mercado Livre API (via scraper) | one spreadsheet per search term |
| 4b | `04b_unify_ml_sheets.R` | `data/raw/ml_sheets/*.xlsx` | `ml_unified_listings.csv` |
| 4c | `04c_recategorize_listings.R` | `ml_recategorized_en.csv` | `ml_recategorized_en_final.csv` |
| 4d | `04d_scientific_name_detection_source_audit.R` | `ml_recategorized_en_final.csv` | `ml_recategorized_scientific_final.csv` |
| 4e | `04e_deduplicate_listings.R` | `ml_recategorized_scientific_final.csv` | `ml_listings_final_deduplicated.csv` (expected: 10,176 listings) |
| 5 | `05_manuscript_figures.R` | ITS results, Mercado Livre data, ANVISA | Figs. 2-4 and 6-10 |
| 6 | `06_time_series_figures.R` | Google Trends series | Figs. 1 and 5A-C |

Steps 3, 5 (Google Trends and ANVISA panels) and 6 can be run directly from the data provided. Steps 4c-4e start from
`ml_recategorized_en.csv`, because the script of the first recategorization pass was not preserved.

**Software.** R 4.5.2 (R Core Team 2025); the packages are listed in [docs/SOFTWARE.md](docs/SOFTWARE.md). Python 3 on Google Colab was used for step 4a (`requirements_collection.txt`). Packages `gtrendsAPI` (Correia 2024) and `gkgraphR` (Correia 2020) are required for steps 1–2.

**Third-party software.** Mercado Livre listings were collected with the scraper [Mercado-Livre-Plants-Scraper](https://github.com/Igor-Britoo/Mercado-Livre-Plants-Scraper) by Igor Brito (MIT License). The original scraper was designed to query plant names as configured in its input files. For this study, we adapted the search-term input through an equivalence dictionary that linked RENISUS scientific names and synonyms to the corresponding Brazilian Portuguese popular names used in online listings. This adaptation was intended to improve the retrieval of relevant advertisements, because listings predominantly use vernacular rather than scientific names. The search terms, categories and subsequent manual filtering and taxonomic auditing are documented in this repository. The original scraper code is not redistributed here; script `scripts/04a_collect_mercado_livre_colab.py` documents how it was run. Please cite the original software as Brito I. (2024).

**API key.** Steps 1-2 need a Google API key. Copy `.Renviron.example` to your user-level `~/.Renviron`, fill in `GOOGLE_API_KEY`
and restart R. The key is never stored in the code.

## Collection dates

| Source | Date |
|---|---|
| Google Trends | 16 March 2024 (series covers 2004-01 to 2023-12) |
| Mercado Livre (scraping) | 8 November 2024 (from the file timestamps of the raw spreadsheets) |
| Mercado Livre (manual filtering) | spreadsheets dated 5 January 2025 |
| ANVISA medicines database | 20 March 2024 |
| RENISUS list | 2009 (Ministério da Saúde) |

Google Trends returns sampled data, so a new collection can give slightly different values; the series used in the study is provided.
ANVISA registry status reflects the database on 20 March 2024 and may have changed since.

## Known limitations

Details are in [docs/PROVENANCE.md](docs/PROVENANCE.md).

- The script of the first recategorization pass of Mercado Livre listings was not preserved; the resulting file is provided as data.
- The original script of Figs. 5A-C was lost; `06_time_series_figures.R` was reconstructed from the Fig. 1 script and may produce figures that
  differ slightly in style from those in the manuscript.
- The time-series results were recomputed independently in Python and matched the manuscript (see docs/PROVENANCE.md).
- Mercado Livre content (titles, IDs, links, prices) belongs to the platform and sellers; it is provided only for reproducibility.
